# Security policy intake evidence

These files are byte-preserved recovery evidence, not implementation acceptance. Historical local
paths describe the original observations and are not portable commands. The approval receipt binds
the exact decision packet; direction approval does not approve any finding, amendment wording,
trusted-service provisioning or merge. Candidate values are absent from these metadata packets.

The original adjudication omits some full native position fields and is not an acceptance-ready
approval registry. Native coordinate and fingerprint qualification must be included in the design.
